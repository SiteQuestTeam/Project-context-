# The app drafts the city paperwork; it does not route around it

An Organisation cannot fix or install anything on city property (e.g. benches on city land) without the city's consent, so the app cannot shorten the process by sending work straight to an NGO. Instead it uses Kraków's existing "Inicjatywa lokalna" procedure, where residents, directly or through an NGO, apply to carry out a public task together with the city (installing benches is the city's own example, and applications are accepted all year). The app's job is to write the Application draft from the Need, its Comments and its Supports, so the paperwork is shorter, not skipped.
